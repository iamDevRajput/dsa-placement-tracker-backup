🌐 Browser Storage Sandboxing & Origin Boundaries

Browser storage (both LocalStorage and IndexedDB) is strictly isolated by origin (protocol + domain + port).

  • Local File URL: If you open file:///Users/.../index.html directly, storage is isolated to that specific file path.
  • Local Web Server: If you run ./start-server.sh and open http://localhost:8000, storage is isolated to localhost:8000.
  • Different Browsers: Google Chrome, Apple Safari, Brave, and Edge maintain independent storage sandboxes.
  • Incognito / Private Windows: Private windows do not share storage with normal windows and discard data upon close.
